Knowledge & Guidance

Frequently Asked Questions

Everything you need to know about garment label printing, barcode scanning, multi-staff sync, and network requirements.

Bluetooth & ESC/POS

How do I print barcode labels & price tags for garments?

StockGrid supports direct wireless Bluetooth Thermal Label Printers (58mm, 80mm, and standard 50mm × 25mm / 2"×1" garment sticker rolls) using standard ESC/POS commands. You can also generate one-click high-resolution PDF sticker grids formatted for standard A4 adhesive paper to print with laser/inkjet printers.

Continuous Multi-Scan

Can I scan existing manufacturer barcodes on shipments?

Yes! StockGrid's continuous batch camera scanner supports all 1D & 2D formats (EAN-13, UPC-A, Code 128, Code 39, QR Code). Features include instant audio beep feedback, continuous multi-item scanning, and LED flashlight assist for dimly lit stockrooms.

Cloud-Synced Mesh

How does multi-device sync work across floor staff?

Powered by the Grid Weave™ Synchronization Engine and Supabase Postgres, stock movements recorded by staff automatically synchronize across all registered employee and admin devices with automated background polling and instant manual pull-to-refresh.

Cloud Architecture

What internet connectivity is required for StockGrid?

StockGrid operates as a live, synchronized cloud platform powered by Supabase PostgreSQL. A standard mobile data connection (4G/5G) or local Wi-Fi network is required to record stock entries, scan barcodes, and sync transactions across devices. Instant error feedback and network status indicators alert staff immediately if a network drop occurs.

4-Digit Master PIN

Can floor workers see our wholesale purchase costs?

No. In Staff Mode, sensitive financial figures like total inventory valuation (₹ 48,25,000), profit margins, and export reports remain private. Floor workers see piece counts and size distributions needed for operational scanning, protected by the 4-digit Master PIN.

Apparel Size Matrix

How are garment sizes and apparel variants tracked?

StockGrid natively supports standard apparel size matrices (S, M, L, XL, XXL, 3XL / Waist 28–44) across shirts, kurtis, denim, tops, and ethnic wear. Set minimum safety thresholds per size and receive instant shortage restock alert banners on your home screen.
